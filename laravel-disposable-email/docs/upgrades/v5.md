# Upgrade to 5.x

Replace the old facade:

```php
DisposableEmail::isDisposable($email);
```

With the current API:

```php
use Disposable;

Disposable::email($email);
Disposable::domain($emailOrDomain);
```

The `disposable_email` validation rule and `@disposableEmail` Blade conditional remain available.
