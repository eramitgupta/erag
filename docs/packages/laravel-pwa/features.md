* 🧩 Configurable Add to Home Screen install prompt
* 🔄 Supports Laravel versions 8.x to 12.x
* ⚡ Minimal configuration
* 📱🖥️ Mobile and Desktop support
* 🛠 Customizable via config/pwa.php
* 🧑‍💻 Blade directives
* 🔐 HTTPS ready
* 🌐 Blade, Livewire, Vue & React compatible
