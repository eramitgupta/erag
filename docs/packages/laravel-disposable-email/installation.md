Laravel Disposable Email Detection is distributed as a Composer package and integrates seamlessly with Laravel applications.

The package follows Laravel’s official conventions and supports automatic package discovery, ensuring a smooth and hassle-free installation experience for most projects.

---

### 📦 Install via Composer

To install the package, run the following command from the root directory of your Laravel project:

```bash
composer require erag/laravel-disposable-email
