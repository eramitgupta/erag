- 🔥 **110,646+ Known Disposable Email Domains**  
  Comes preloaded with a large and actively maintainable list of disposable and temporary email domains to block fake signups instantly.

- 🧠 **Smart Validation Rule**  
  Seamlessly integrates with Laravel’s validation system, allowing you to block disposable emails directly in Form Requests and controllers.

- ⚙️ **Runtime Email Detection**  
  Check emails programmatically at runtime using a helper method or facade for advanced business logic and conditional flows.

- 🧩 **Blade Directive Support**  
  Includes a Blade directive to easily handle conditional UI rendering based on disposable email detection.

- 🌐 **Remote Domain List Sync**  
  Automatically or manually sync disposable email domain lists from remote sources to keep your protection up to date.

- 📝 **Custom Disposable Domain Blacklist**  
  Easily extend the default list by adding your own disposable domains without modifying package code.

- 🚀 **Optional Caching Support**  
  Improves performance by caching the compiled domain list, ideal for high-traffic and large-scale applications.

- ⚡ **Zero-Configuration Setup**  
  Works out of the box with sensible defaults and provides a publishable configuration file for customization when needed.

- ✅ **Laravel 10, 11, and 12 Compatible**  
  Fully compatible with modern Laravel versions and follows Laravel best practices.
