# Installation

Getting started with **@erag/vue-toastification** is very easy.  
You just need to install the package and register it once in your Vue app.

No complex configuration. No extra dependencies.

---

## 📦 Install the Package

Install the package using **npm**:


```sh [npm]
npm install @erag/vue-toastification
```
